# Todo for My Dog

## Who · What · Why · When · Where

- **Who:** My Dog. One list for one dog, kept by the person who looks after the dog.
- **What:** It holds three tasks: Go for a walk · Poop in the yard · Ask for refills.
- **Why:** The dog sometimes does not eat, and sometimes poops in the wrong place. A list of what still needs doing helps fix that.
- **When:** Anytime — in the morning and at night.
- **Where:** On a phone, or on any other device.

## The 4 parts

- **Data (the tasks):** each task is a short line of text, and it is either done or not done. The three starting tasks are Go for a walk, Poop in the yard and Ask for refills.
- **Display (what the user sees):** the big title "Todo for My Dog" and the list of tasks under it, with each task showing if it is done.
- **Actions (what the user can do):** add a task, tick a task as done, delete a task, and filter the list (all tasks, not done, done).
- **Memory (localStorage):** the tasks are kept in the browser under the key `todo-app`, so they are still there after a reload. If the saved data is missing or broken, the app starts with an empty list.

## Done when

- [ ] A task can be added in 5 seconds or less.
- [ ] Tasks can be toggled as completed or not.
- [ ] Tasks are still there after a reload.
